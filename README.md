# Расписание преподавателя

Статический сайт без сервера. Загружает XLSX, находит занятия выбранного преподавателя и показывает удобное недельное расписание.

## Публикация на GitHub Pages

1. Загрузите всё содержимое этой папки в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки.

В проект уже добавлен исходный файл `files/schedule.xlsx`. При первой загрузке он откроется автоматически. Новый файл, загруженный через интерфейс, сохраняется в IndexedDB текущего браузера.

## Важно

GitHub Pages — статический хостинг, поэтому сайт не может менять файлы внутри репозитория. Загруженный XLSX хранится локально в браузере пользователя и остаётся после перезагрузки страницы. На новом устройстве файл необходимо загрузить ещё раз.
